💡 Tips for Best Results

🖼️

Use high-resolution character images (min 300×300px) with clear lighting.

🎬

Choose reference videos with clear, isolated motion patterns (3–30 seconds).

🎯

Use "Video Mode" for active movements like dancing, walking, or full body.

✍️

Adding a descriptive prompt helps guide the AI in interpreting reference gestures.

⚙️

Start with CFG Scale 0.5 — lower values look more natural, higher adhere strictly to prompts.

⭐

Use Pro quality tier for production output, and Standard for testing drafts quickly.
